# Product quality for Danvar

State the visitor task and one primary action per scene. Keep navigation, pause and skip discoverable. Offer personalization as a choice and respect system motion and appearance preferences. Test first visit, returning visitor, mobile, keyboard and all three languages.

Use real team experience and accurately describe employment versus work through another company. Avoid fabricated clients, scarcity, testimonials, metrics or expertise. Mark unfinished photo and contact flows honestly. Keep input local until a real submission path is authorized.

Apply progressive disclosure: a concise scene first, detail on request, clear outcome after each action. Validate understanding and task completion before adding animation. Review Arabic and Persian reading order, labels and font shaping.

Use Google's primary documentation for web quality: https://web.dev/articles/vitals and https://developers.google.com/search/docs/fundamentals/seo-starter-guide . Evaluate LCP, INP and CLS using lab evidence and field evidence when available. Do not invent GEO scores or promise rankings. Analytics, Search Console and Tag Manager are separate integrations requiring real configuration; do not install trackers by assumption.

Record the hypothesis, intended audience, success signal, validation and remaining uncertainty in the review document. Recommend experiments only where traffic and user consent support meaningful measurement.
